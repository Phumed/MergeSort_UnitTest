## Installation

1. Clone the repository:

   ```bash
   git clone <your-repo-url> merge-sorted-arrays
   cd typescript-merge-sort
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Build the TypeScript code:
   ```bash
   npm run build
   ```

## Usage

To run the program with an example:

```bash
npm start
```

To run the unit tests with Jest:

```bash
npm test
```
